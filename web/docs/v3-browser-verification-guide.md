## 验证步骤

### Step 1: 创建会话
1. 在输入框中键入创意，如 "一个江湖侠客复仇的故事"
2. 选择风格（如 武侠）
3. 点击 "开始创作"

**预期**:
- [ ] 左侧工作区出现 "步骤面板"
- [ ] 右侧 ChatPanel 出现预确认提示框 "确认执行: 故事构思"
- [ ] 三个按钮可见: "确认执行" / "修改后执行" / "取消"

### Step 2: 预确认门 — 修改后执行
1. 点击 "修改后执行" 按钮

**预期**:
- [ ] 出现文本输入框
- [ ] 输入 "调整为主角是女性侠客" 后点击 "提交修改"
- [ ] ChatPanel 显示 "已提交修改请求"

### Step 3: 预确认门 — 确认执行
1. 再次出现预确认提示后，点击 "确认执行"

**预期**:
- [ ] 左侧步骤面板显示 "故事构思 — 生成中"
- [ ] 进度条走动
- [ ] 完成后出现后确认提示

### Step 4: 后确认门
1. 审阅生成的故事内容
2. 点击 "确认，进入下一步"

**预期**:
- [ ] 步骤自动推进到 "角色提取"
- [ ] 出现新的预确认提示

### Step 5: 完整 6 步流程
依次完成以下步骤的确认:
1. 故事构思 → 确认
2. 角色提取 → 确认
3. 剧本编写 → 确认
4. 分镜设计 → 确认（多场景，每个场景确认一次）
5. 角色肖像 → 确认
6. 视频渲染 → 自动完成

**预期**:
- [ ] 每一步都有预确认门 → 执行 → 后确认门
- [ ] WorkArea 和 ChatPanel 双向同步（一侧确认后另一侧显示 "正在确认中"）

### Step 6: ChatPanel 修改后执行按钮（B2 验证）
1. 在任一步骤的预确认阶段
2. 在 ChatPanel 中点击 "修改后执行"
3. 输入修改意见
4. 提交

**预期**:
- [ ] 按钮可见且有琥珀色高亮样式
- [ ] 输入框可输入文本
- [ ] 提交后在 ChatPanel 显示系统消息
