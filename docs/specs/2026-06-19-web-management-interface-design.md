## 一、产品定位

### 1.1 核心定位

**独立创作型 AI 短剧生成工具**。景区运营人员一个人完成从想法到成片的全部流程——输入创意、AI 自动生成故事/角色/分镜/视频、预览导出。无需任何专业技能。

### 1.2 目标用户

景区运营人员（非技术人员），典型场景：小王想为五一活动做一个预热短视频。

### 1.3 技术选型

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | React + Vite + TypeScript + shadcn/ui + TailwindCSS | 组件化 SPA |
| 后端 | FastAPI (Python) | 直接导入现有 ViMax 管线 |
| 实时通信 | WebSocket | 管线进度推送到前端 |
| AI 对话 | Claude Agent SDK | 右侧对话面板的 AI 创作助手 |
| 存储 | 本地文件系统 (.vimax/ + .working_dir/) | 复用现有 SessionIndex |
| 认证 | 无（MVP 单用户） | — |

## 七、AI 对话面板设计

### 7.1 技术方案

通过 **Claude Agent SDK** 实现。Agent 拥有操作当前会话的工具：

| 工具 | 说明 |
|------|------|
| `update_story_text` | 修改故事文本 |
| `update_character` | 修改角色名称/描述 |
| `regenerate_planning_item` | 重新生成某个规划产出 |
| `regenerate_character_portrait` | 重新生成指定角色的肖像 |
| `regenerate_shot_frame` | 重新生成指定镜头的首帧 |
| `get_session_status` | 获取当前会话状态和产物清单 |
| `get_step_context` | 获取当前步骤的完整上下文 |

### 7.2 智能行为

- **主动汇报**：进入新步骤时，Agent 发一条概括当前状态的消息
- **上下文感知**：Agent 知道当前步骤、产物清单、哪些可以操作
- **驱动 UI**：Agent 的工具调用结果实时反映在左侧面板

### 7.3 示例对话流（Step 4 子阶段 A）

```
[系统] 进入 Step 4 — 角色肖像生成阶段
[AI]  "角色形象开始生成了！我会为每个角色生成正面、侧面、背面三张图。
       完成后你可以逐个确认。"
       ... 生成中 ...
[AI]  "武松的肖像已生成，左侧可以查看。看看满意吗？"

[用户] "武松的发型太现代了，改成古装束发，表情再坚毅一点"
[AI]  "好的，我来调整武松的形象——古装束发、表情更加坚毅。稍等..."
       [调用 regenerate_character_portrait(character="武松")]
       ... 生成完成，左侧更新 ...
[AI]  "武松的新形象已生成！束发造型，眼神也更坚毅了。这次怎么样？"

[用户] "好多了，确认"
[AI]  "已确认。店家也生成好了，继续吗？"
```

## 八、错误处理与重试

### 8.1 生成失败处理

| 策略 | 说明 |
|------|------|
| 自动静默重试 | 单步骤失败自动重试 1-3 次 |
| 降级展示 | 多次重试仍失败 → 该位置显示占位标记 + "重试"按钮 |
| 断点续传 | 已完成的中间产物不重新生成 |

### 8.2 API Key 未配置

启动时检查 → 若缺少 API key → 主工作区显示配置引导

### 8.3 取消生成

Step 4 始终显示"取消"按钮 → 取消后保留已完成的部分产物 → 可随时重新开始

## 九、数据流

### 9.1 创建短剧完整数据流

```
Step 1: 用户填写创意 + 风格
    │ POST /api/sessions {idea, style}
    │ → {session_id}
    ▼
Step 2: 用户点击"AI 生成规划"
    │ POST /api/pipeline/plan {session_id, idea, user_requirement, style}
    │ → 202 Accepted
    │ WebSocket 连接 /ws/pipeline/{session_id}
    │ 后端 asyncio.Task 执行：
    │   1. Idea2VideoPipeline.develop_story()
    │   2. Idea2VideoPipeline.extract_characters()
    │   3. Idea2VideoPipeline.write_script_based_on_story()
    │   4. Script2VideoPipeline.plan_text_artifacts() per scene
    │ WebSocket 推送 artifact_ready 事件
    │ 前端获取 JSON 文件渲染 UI
    ▼
Step 3: 分镜 → 用户审阅（纯前端，数据已在 Step 2 生成）
    │ 可通过 AI 对话修改
    ▼
Step 4: 用户点击"开始生成视频"
    │ POST /api/pipeline/render {session_id}
    │ → 202 Accepted
    │ WebSocket 推送 render_progress 事件
    │ 子阶段 A: 角色肖像 → 用户确认
    │ 子阶段 B: 首帧图 → 用户确认
    │ 子阶段 C: 视频自动生成
    │ WebSocket 推送 pipeline_complete
    ▼
Step 5: 视频播放 + 下载
    GET /api/files/{session_id}/idea2video/final_video.mp4
```

### 9.2 WebSocket 事件类型

```json
// 管线状态
{"type": "pipeline_status", "stage": "develop_story", "phase": "started"}
{"type": "pipeline_status", "stage": "develop_story", "phase": "done"}

// 制品就绪
{"type": "artifact_ready", "path": "story.txt", "url": "/api/files/.../story.txt"}
{"type": "artifact_ready", "path": "characters.json", "url": "/api/files/.../characters.json"}

// 渲染进度
{"type": "render_progress", "stage": "character_portrait", "phase": "done",
 "character": "武松", "view": "front", "image_url": "/api/files/.../front.png"}

// 完成/错误
{"type": "pipeline_complete", "final_video_url": "/api/files/.../final_video.mp4"}
{"type": "pipeline_error", "error": "API timeout at shot 3"}
```
